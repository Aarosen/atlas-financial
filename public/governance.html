Atlas Model Card & AI Governance

Published version 1.0 · Last reviewed: 2026-05-08

1. Purpose

Atlas helps individuals understand their personal financial position and pick the single highest-leverage next step. Atlas does not give regulated investment, tax, or legal advice.

2. System composition

ComponentWhat it doesSource of authority
Conversational layer (Claude Sonnet 4.5 via Anthropic API proxy) Asks empathetic questions; extracts numbers from free text; explains the engine's output in plain language. Used for language only. Never used as the source of truth for any number, tier, or recommendation.
Deterministic Engine (in-app JS class) Computes buffer months, allocation %, debt-to-income, tier, lever, and one-step suggested amount. Sole source of truth for all numerical recommendations. Code is open-source: github.com/Aarosen/atlas-financial.
Specialized calculators (50/30/20, debt snowball/avalanche, cash-flow simulator, what-if, plan builder) Deterministic, auditable math. Pure JS, no LLM calls. Reproducible from inputs.
Plaid (read-only, optional) Pulls transaction history when the user connects. Plaid Inc., used only for the transactions product. No auth, transfer, or balance access.

3. Model risk register

RiskLikelihoodImpactMitigation
LLM hallucinates a number when extracting from chat Medium High Engine never reads LLM-generated text as a number for recommendations. Extracted fields are routed through a regex-based fallback validator before being committed.
LLM produces persuasive but wrong financial guidance Low High System prompt forbids the model from giving recommendations; the user-visible recommendation comes only from the deterministic engine. Each tier reveal includes "Why am I seeing this?" with a full decision trace.
Plaid data drift (categorization mismatch) Medium Medium Atlas re-runs categorization in-app via deterministic rules, ignoring Plaid's category labels.
Edge function rate limit cascade Low Low 20 req/min/IP soft limit; on 429 the app degrades to local fallback parsing.
User mistakes Atlas for licensed advice Medium High Disclaimer on landing screen + this page. No "buy this stock"-style outputs ever.

4. FS AI RMF mapping (selected controls)

Control areaHow Atlas implements it
Third-party model risk Anthropic Claude Sonnet 4.5 used for conversation only. Plaid sandbox/production isolated by env. Both vendors have published security/privacy docs linked below.
Human oversight Every recommendation includes a "Why" panel with full trace and a one-click "decline" path. No auto-execution of any financial action.
Transparency This page + in-app Decision Log + open-source codebase.
Robustness Deterministic math layer is unit-testable and version-controlled. LLM fallback path activates on proxy failure.
Fairness Engine logic does not branch on age, race, gender, or zip. Inputs are purely financial.
Privacy All financial numbers stored in the user's browser (IndexedDB). Plaid access tokens stored in browser only. Conversation messages transit through the Anthropic proxy but financial numbers are not transmitted.

  • Disconnect bank: Settings → Bank sync → Disconnect. Calls Plaid /item/remove.
